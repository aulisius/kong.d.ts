# kong.d.ts
TSTL support for Kong/OpenResty

# What is this?

[Kong](https://konghq.com/) is an API Gateway that has a programmable interface in Lua. [TSTL](https://typescripttolua.github.io/) is a project that allows one to author Lua modules in TS which is then transpiled.
When you combine them both, you get to write Kong plugins in TypeScript.
